SheepPro – Livestock Management App with RFID & Bluetooth Scale

My role: Full-Stack Developer – Android (Jetpack Compose) + Python/HTMX/PostgreSQL web

SheepPro is a multi-farm livestock management system for sheep breeders. Farm staff use an Android app built with Jetpack Compose to scan an animal's RFID tag and pull up its record instantly, and to capture weights straight from a wireless Bluetooth scale. They also log births, breeding, lambing groups and sales, then sync data to the server. Owners and admins manage companies, employees, animals, breeding, genomics and records in a Python + HTMX web panel backed by PostgreSQL.

Key features

  • Scan an RFID tag to open the animal record instantly
  • Capture weights straight from a wireless Bluetooth scale
  • Log births, breeding, lambing groups and sales
  • Sync field data to the server
  • Multi-company web admin for companies, employees, animals, breeding, genomics and records

StudyAI – AI Study Agent for Android (Jetpack Compose, LLM Tools)

My role: Android & AI Engineer – Jetpack Compose, MVI, LLM tool calling

StudyAI is an Android AI study agent built with Kotlin and Jetpack Compose using MVI. Students pick a subject and chat with an AI tutor powered by Llama 3.3. The agent uses LLM tool calling to search the web for up-to-date answers, and generative AI to create quizzes on any topic at easy, medium or hard difficulty. Quizzes are graded in the app with correct answers and explanations. Quick-prompt chips, a web search indicator and chat reset keep it simple to use.

Key features

  • Subject picker: Mathematics, Science, History, Programming, Languages and Economics
  • AI tutor chat powered by Llama 3.3, scoped to the chosen subject
  • LLM tool calling: the agent decides when to search the web for up-to-date answers
  • Quiz generator: enter any topic and pick Easy, Medium or Hard
  • Instant grading with a score summary and an explanation for every question
  • Quick-prompt chips and one-tap chat reset

Aura Face Building – AI Face Analysis App (Compose Multiplatform)

My role: Solo Mobile & AI Engineer – Android + iOS, Compose Multiplatform, custom TFLite models

A face-analysis and self-improvement app for Android and iOS, built solo from one Kotlin codebase with Compose Multiplatform. Users take three guided photos; TensorFlow Lite models I trained run on the phone to detect the face and score features such as jawline, skin clarity, symmetry and leanness.
